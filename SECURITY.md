# Security Policy

This repo contains educational scripts and templates, not production software.

## Reporting
If you find an unsafe instruction (for example, a lab that could expose data, grant excessive permissions, or incur unexpected cost), please report it privately via GitHub's *Report a vulnerability* feature (Security tab) or contact the maintainer through [ashutoshkandpal.com](https://ashutoshkandpal.com). Do not post sensitive details in public issues.

## Handling secrets
Never commit tenant IDs, subscription IDs, keys, tokens, or credentials. Use placeholders and repository variables.

## Scope
Run labs only in sandbox environments you own. The maintainers are not responsible for changes or costs in your environment.
