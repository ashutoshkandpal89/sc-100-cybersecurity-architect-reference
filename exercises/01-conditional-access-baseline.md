# Exercise 1 — Conditional Access Baseline

**Scenario:** 3,000 users, mixed managed/BYOD devices, 40 partner guests, 2 admin teams.

## Tasks
1. List the policies you would create (name, users, apps, conditions, grant/session controls).
2. Define exclusions and break-glass handling.
3. Decide which policies start in **report-only** and for how long.
4. Define how you will monitor impact (sign-in logs, CA insights workbook).
5. Add a guest-specific policy and justify the controls.

## Self-check
- [ ] Legacy auth blocked
- [ ] Admins require phishing-resistant MFA
- [ ] Security-info registration protected
- [ ] Device compliance used for sensitive apps
- [ ] Two monitored break-glass accounts
- [ ] Rollback plan documented

## Optional hands-on
Create one policy in report-only mode in a lab tenant and review its effect in sign-in logs.
