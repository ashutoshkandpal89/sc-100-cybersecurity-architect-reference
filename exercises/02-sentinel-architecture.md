# Exercise 2 — Sentinel Architecture

**Scenario:** Global company, data residency rules for the EU, on-prem firewalls, AWS accounts, Entra, M365, Defender XDR.

## Tasks
1. Decide the workspace count and justify it.
2. List data sources and the connector method for each.
3. Classify tables into analytics, basic, and auxiliary tiers with retention.
4. Define RBAC (who reads, responds, authors rules).
5. Choose three automation rules and one playbook; list required permissions.
6. Estimate the main cost drivers and two ways to reduce them.
